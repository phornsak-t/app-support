# App Support
Central GitHub Pages support site for apps by Phornsak Tibyakad.

Each application has a separate folder and separate privacy policy.

- `/tarot-horoscope/`: Tarot Horoscope / ดูดวงไพ่ทาโร
- `/camera-editor-beauty/`: Existing Camera Editor Beauty pages copied without policy changes. Existing published URLs remain available.

To add an app: create its folder, add index.html, support.html and privacy.html, and add a link on the root index. Describe actual app and SDK behavior individually. Do not apply one shared privacy policy to different apps.

No analytics or advertising scripts are included on this site. Publishing is configured through GitHub Pages from main at the repository root.
